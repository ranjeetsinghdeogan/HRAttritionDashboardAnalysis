# HR Attrition Dashboard Analysis

## Project Overview

This project focuses on analyzing employee attrition data to understand workforce trends and identify factors affecting employee turnover. The objective was to build an interactive dashboard that displays attrition rates across departments, job roles, and employee tenure.

## What I Did

* Imported HR attrition data using Power Query
* Created a calculated column **Attrition_Flag** to identify employees who left the company
* Built PivotTables to calculate attrition rate by Department and Job Role
* Added slicers to filter data by Gender and Education Field
* Designed a one-page interactive dashboard with key performance indicators and charts

## How I Did It

* Used Microsoft Excel / Power BI for data analysis and visualization
* Applied formulas to calculate attrition percentage
* Used PivotTables to summarize employee data
* Created visualizations such as KPI cards, bar charts, and column charts
* Used slicers to enable dynamic filtering of dashboard results

## Result

* Successfully calculated overall employee attrition rate
* Identified departments and job roles with higher attrition levels
* Analyzed employee retention based on years at the company
* Built an interactive dashboard to support HR decision-making
* Demonstrated practical skills in data analysis and dashboard design

* Microsoft Excel / Power BI
* Power Query
* PivotTables
* Data Visualization
